# HORECA Calculator Service 📊

### Senior-Level Business Analytics & Order Management System

**HORECA Calculator Service** — это высокотехнологичная B2B-платформа,
разработанная для автоматизации расчетов, управления заказами и глубокой
аналитики в секторе HORECA (HoReCa: Hotels, Restaurants, Catering). Система
объединяет в себе функционал CRM, ERP и аналитического хаба.

---

## 🚀 Основной функционал

### 1. Аналитический Дашборд (Manager Dashboard)

- **Пульс оборота:** Динамический мониторинг объема сделок в реальном времени.
- **Эффективность статусов:** Визуализация воронки продаж и конверсии на каждом
  этапе (от черновика до оплаты и отгрузки).
- **Экспертиза портфеля:** Радар-чарт для анализа распределения проектов по
  категориям (оборудование, мебель, текстиль и т.д.).
- **Activity Feed:** Живая лента событий по всем активным расчетам.

### 2. Расчетный Центр (Calculation Engine)

- Создание сложных многопозиционных расчетов с учетом специфики оборудования.
- Многоэтапная система валидации (Draft → Expert Review → Revision).
- Экспорт документации в форматах **PDF** (с использованием jsPDF) и **Excel**
  (xlsx).

### 3. Коммуникационная Платформа

- **Project Chat:** Интегрированный чат для обсуждения конкретного расчета между
  менеджером и клиентом.
- **Real-time:** Мгновенные уведомления и обновления статусов через Supabase
  Broadcast.
- **Read Receipts:** Визуальные индикаторы прочтения сообщений.

## 🛠 Технологический Стек

### Frontend

- **React 19 & TypeScript:** Фундамент приложения с использованием последних
  стандартов.
- **Vite:** Сверхбыстрая сборка и Hot Module Replacement.
- **Tailwind CSS 4.0:** Использование современной системы стилизации с упором на
  переменные и производительность.
- **TanStack Query v5:** Умное управление серверным состоянием, кэшированием и
  пагинацией.
- **Recharts:** Библиотека для отрисовки сложных интерактивных графиков.
- **Framer Motion:** Вспомогательные анимации для интерфейса.
- **React Router 7:** Навигация между модулями приложения.

### Backend & Infrastructure

- **Supabase:** Full-stack решение, выполняющее роль БД (PostgreSQL),
  Auth-провайдера и системы Real-time подписок.
- **PostgreSQL:** Хранение данных с использованием RLS (Row Level Security) для
  разграничения доступа.

### Quality Assurance & Tools

- **Vitest:** Современное unit и integration тестирование.
- **ESLint & Prettier:** Строгий контроль качества кода и форматирования.
- **Zod:** Runtime-валидация данных и типизация форм.

---

## 🏛 Архитектурные Особенности

- **Feature-Sliced Design (Elements):** Код организован по фичам (`dashboard`,
  `chat`, `auth`), что упрощает масштабирование.
- **Custom Chart Architecture:** Использование проприетарной обертки
  `ChartContainer` для предотвращения ошибок рендеринга и обеспечения
  стабильности Layout.
- **Optimistic UI:** Мгновенное обновление интерфейса в чате и при смене
  статусов без ожидания ответа сервера.
