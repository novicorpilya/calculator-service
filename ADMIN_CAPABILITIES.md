# Возможности Панели Администратора

Этот документ описывает текущий функционал, доступный пользователям с ролью
`admin` в системе.

## 1. Общая статистика (Overview)

- **Суммарные показатели**: Просмотр общего количества пользователей и ожидающих
  регистрации приглашений.
- **Финансовые показатели**: Мониторинг общего бюджета всех проектов и
  "pipeline" выручки (проекты на стадиях выставления счета и завершения).
- **Активность по стадиям**: Визуализация количества проектов на каждом этапе
  (Черновик, Отправлено, Экспертиза, Поставщики, Счет, Завершено).

## 2. Управление командой (Team Management)

- **Список пользователей**: Просмотр всех зарегистрированных пользователей
  системы с их контактными данными и ролями.
- **Управление ролями**: Возможность изменять роль любого пользователя
  (`client`, `manager`, `admin`).
- **Блокировка**: Возможность временно заблокировать доступ пользователя к
  системе.
- **Удаление**: Полное удаление профиля пользователя из базы данных.

## 3. Система приглашений (Invitations)

- **Создание инвайтов**: Генерация уникальных токенов для регистрации новых
  пользователей с заранее определенной ролью.
- **Email-рассылка**: Автоматическая отправка ссылки на регистрацию через сервис
  уведомлений.
- **Ручное копирование**: Возможность скопировать прямую ссылку на регистрацию
  для передачи через другие каналы.
- **Контроль статсусов**: Отслеживание, было ли приглашение использовано или оно
  все еще ожидает регистрации.

## 4. Управление проектами (Calculations)

- **Полный доступ**: Просмотр абсолютно всех расчетов, созданных в системе
  (включая клиентские черновики).
- **Откат статусов (Return to Stage)**: Возможность вернуть проект на предыдущую
  стадию (например, из "Счета" обратно в "Экспертизу"), если была допущена
  ошибка.
- **Удаление проектов**: Право на безвозвратное удаление любого расчета из
  системы.

## 5. Аудит и безопасность

- **Журнал событий (Audit Logs)**: Просмотр детальной истории системных
  действий:
  - Кто и когда создал приглашение.
  - Изменения ролей пользователей.
  - Блокировки и удаления.
  - Административные действия над расчетами.
