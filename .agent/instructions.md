# Agent Instructions

All terminal commands must be executed using the Cmder Bash shell. Since
`bash.exe` is not in the system PATH, use the full path:
`C:\Console_Cmder\vendor\git-for-windows\bin\bash.exe`.

Example: `C:\Console_Cmder\vendor\git-for-windows\bin\bash.exe -c "ls -la"`

Always prefer bash syntax over cmd/powershell syntax.
