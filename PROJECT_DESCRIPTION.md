# 🎯 Описание проекта: Calculator Service

## 📋 Обзор проекта

**Calculator Service** — это современное веб-приложение для HoReCa (гостинично-ресторанного) сектора, реализующее систему аутентификации и авторизации с использованием Supabase в качестве Backend-as-a-Service (BaaS).

### Технологический стек

- **Frontend Framework**: React 19.2.0 с TypeScript
- **Build Tool**: Vite 7.2.4
- **Styling**: Tailwind CSS 4.1.18
- **Backend**: Supabase (PostgreSQL + Auth + Real-time)
- **State Management**: React Context API
- **HTTP Client**: Axios (для будущих API запросов)
- **Icons**: Lucide React

## 🔐 Система аутентификации

### Реализованный функционал

#### 1. **Регистрация пользователя**
- Валидация всех полей на клиенте (до отправки на сервер)
- Проверка сложности пароля (8+ символов, заглавные, строчные, цифры, спецсимволы)
- Проверка совпадения паролей
- Автоматическое создание профиля через database trigger
- Сохранение дополнительных данных (организация, телефон, адрес)

#### 2. **Вход в систему**
- Валидация email и пароля
- Функция "Запомнить меня" (сохранение credentials в localStorage)
- Автоматическая загрузка сохраненных данных
- Обработка ошибок с понятными сообщениями

#### 3. **Валидация форм**
- **OnBlur валидация**: Проверка при потере фокуса
- **Real-time валидация**: Обновление ошибок при вводе (для touched полей)
- **Pre-submit валидация**: Проверка всех полей перед отправкой
- **Связанная валидация**: Автоматическая перевалидация confirmPassword при изменении password

#### 4. **Управление сессиями**
- Автоматическое управление через Supabase
- Отслеживание изменений через `onAuthStateChange`
- Восстановление сессии при перезагрузке страницы
- Безопасное хранение токенов (Supabase управляет внутренне)

## 🛡️ Безопасность

### Реализованные меры безопасности

1. **Аутентификация через Supabase**
   - ✅ Пароли хешируются на стороне Supabase (bcrypt)
   - ✅ JWT токены с автоматическим обновлением
   - ✅ Защита от SQL injection (Supabase ORM)
   - ✅ Rate limiting (встроенный в Supabase)

2. **Валидация данных**
   - ✅ Клиентская валидация всех полей
   - ✅ Проверка формата email (regex)
   - ✅ Сложные требования к паролю
   - ✅ Санитизация входных данных (trim)

3. **Хранение данных**
   - ✅ Токены управляются Supabase (не в localStorage)
   - ✅ "Запомнить меня" - опциональное хранение в localStorage (только для UX)
   - ✅ RLS (Row Level Security) политики в production SQL скрипте

4. **Защита от атак**
   - ✅ XSS: React автоматически экранирует данные
   - ✅ CSRF: Supabase использует SameSite cookies
   - ✅ Брутфорс: Rate limiting в Supabase

## 📦 Ключевые компоненты

### 1. **AuthProvider** (`src/app/providers/AuthProvider.tsx`)
- Управление глобальным состоянием аутентификации
- Инициализация сессии при загрузке приложения
- Слушатель изменений auth state
- Методы: `login`, `register`, `logout`

### 2. **authService** (`src/features/auth/auth.service.ts`)
- Абстракция над Supabase Auth API
- Обработка регистрации с retry логикой для database trigger
- Обновление профиля пользователя
- Получение текущего пользователя

### 3. **useAuthForm** (`src/hooks/useAuthForm.ts`)
- Управление состоянием форм (login/register)
- Валидация полей
- Обработка "Запомнить меня"
- Сохранение/загрузка credentials

### 4. **LoginForm / RegisterForm**
- UI компоненты с валидацией
- Отображение ошибок под каждым полем
- Интеграция с useAuthForm

## 📊 База данных (Supabase)

### Таблица `profiles`
```sql
- id (UUID, PK, FK → auth.users)
- email (VARCHAR, UNIQUE)
- organization_name (VARCHAR)
- phone (VARCHAR)
- address (TEXT)
- role (VARCHAR: 'client' | 'manager' | 'admin')
- created_at (TIMESTAMPTZ)
- updated_at (TIMESTAMPTZ)
```

### Database Triggers
- `handle_new_user()`: Автоматическое создание профиля при регистрации
- `update_updated_at()`: Автоматическое обновление timestamp

### RLS Политики (production)
- Пользователь может читать только свой профиль
- Пользователь может обновлять только свой профиль
- Админы могут читать/обновлять все профили (опционально)

## 🚀 Развертывание

### Переменные окружения
```env
VITE_SUPABASE_URL=your_supabase_url
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
```

1. **Настроить Supabase**
   - Создать проект в Supabase

   - Настроить password requirements

2. **Собрать проект**
   ```bash
   npm run build
   ```

3. **Деплой**
   - Загрузить `dist/` на хостинг (Vercel, Netlify, etc.)
   - Настроить переменные окружения

## 💡 Ключевые решения

### Почему Supabase?
- ✅ Готовая инфраструктура (Auth, Database, Storage)
- ✅ Автоматическое масштабирование
- ✅ Встроенная безопасность
- ✅ Real-time возможности
- ✅ Бесплатный tier для старта

### Почему React Context вместо Redux?
- ✅ Меньше boilerplate кода
- ✅ Достаточно для текущего масштаба
- ✅ Легко мигрировать на Redux/Zustand при необходимости

### Почему Tailwind CSS?
- ✅ Utility-first подход
- ✅ Быстрая разработка
- ✅ Малый bundle size (purge CSS)
- ✅ Современный дизайн из коробки
