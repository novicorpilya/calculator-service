# Описание Проекта: Calculator Service (HoReCa Inventory System)

## 🎯 Цель проекта
Разработка интеллектуальной платформы для автоматизированного расчета, подбора и закупки инвентаря для предприятий сегмента HoReCa (отели, рестораны, кафе, производства). Система призвана заменить ручные подсчеты в Excel, предоставляя профессиональный инструмент с учетом санитарных норм (HACCP), зонирования и интенсивности использования объектов.

Ключевая задача — обеспечить полный цикл сделки: от предварительного расчета пользователем до экспертной проверки менеджером, выставления счета и отслеживания поставки.

## 🛠 Технологический стек

### Frontend
- **Framework**: React 18+
- **Language**: TypeScript (строгая типизация)
- **Styling**: Tailwind CSS (кастомная дизайн-система, Glassmorphism, адаптивность)
- **Icons**: Lucide React
- **Build Tool**: Vite
- **Utilities**: `clsx`, `tailwind-merge`, `sonner` (уведомления), `xlsx` (экспорт данных), `emoji-picker-react`.

### Backend & Infrastructure
- **BaaS (Backend-as-a-Service)**: Supabase
  - **Database**: PostgreSQL (со сложными связями и JSONB полями для гибкости структур расчетов).
  - **Auth**: Supabase Auth (Email/Password, Row Level Security policies).
  - **Realtime**: Supabase Realtime (синхронизация чатов, статусов проектов и уведомлений).
  - **Storage**: Supabase Storage (хранение изображений и вложений в чатах).

### Архитектура и Паттерны
- **Dependency Injection (DI)**: Собственная реализация IoC контейнера (`ServiceContainer`) для управления зависимостями и инъекции сервисов через React Context.
- **Service Layer**: Изолированная бизнес-логика в типизированных классах-сервисах (`CalculationService`, `ChatService`, `AdminService`, `VenueService`, `InventoryService` и др.).
- **Role-Based Access Control (RBAC)**: Строгое разграничение прав доступа и интерфейсов для ролей `Client`, `Manager`, `Admin` как на уровне UI, так и на уровне RLS в базе данных.

## 🌍 Масштаб и Функциональность

### Ролевая Модель
1. **Клиент**:
   - Создание расчетов через интерактивный мастер (Wizard).
   - Ввод параметров помещения (площадь, зоны, уровни загрязнения).
   - Просмотр предварительной сметы и спецификации.
   - Коммуникация с менеджером через встроенный чат.
2. **Менеджер (Эксперт)**:
   - "Воронка проектов" (Kanban/List view) для управления лидами.
   - Аудит расчетов: возможность редактировать параметры клиента.
   - Подбор конкретных SKU товаров из мастер-инвентаря.
   - Выставление счетов и смена статусов жизненного цикла сделки.
3. **Администратор**:
   - Управление пользователями и приглашениями (Invite System).
   - Системный аудит (Audit Logs) всех критических действий.
   - Глобальная аналитика (бюджеты, активность, здоровье системы).

### Ключевые Модули
- **Calculation Engine**: Алгоритмическое ядро для расчета потребностей в инвентаре на основе нормативов площади, количества персонала, посещаемости и коэффициентов интенсивности/резерва.
- **Global Chat Hub**: Централизованная система обмена сообщениями, привязанная к контексту конкретного проекта, с поддержкой вложений и превью изображений.
- **Inventory & Venue Management**: Управление справочниками заведений (Venue) и глобальным каталогом товаров (Inventory Master) с ценами и поставщиками.
- **Export System**: Генерация и скачивание спецификаций и счетов в формате Excel/PDF.

## 💎 Особенности UX/UI
- **Premium Design**: Использование стилистики "Glassmorphism" (эффекты стекла, размытия), глубоких теней, градиентов и curated цветовых палитр.
- **Micro-interactions**: Плавные анимации появления, переходов между страницами, интерактивные состояния кнопок и карточек.
- **Responsive Interface**: Полная адаптивность интерфейса от мобильных устройств до широкоформатных мониторов.
- **Middle+ Code Quality**: Использование типизированных интерфейсов, мемоизации (`useMemo`, `useCallback`), обработки ошибок (`try-catch`, `ErrorBoundary`) и чистого кода.
