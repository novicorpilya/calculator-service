# Функционал Панели Администратора (HICS)

Этот документ описывает текущие возможности и разделы панели администратора в
системе HICS.

## 1. Обзор и Аналитика (Overview)

Главная страница с ключевыми показателями системы.

- **Метрики**:
  - Общий глобальный бюджет проектов.
  - Pipeline выручка (потенциальная прибыль).
  - Количество активных проектов.
  - Общее количество пользователей.
- **Автоматическое обновление**: Данные обновляются в реальном времени (каждые
  30 секунд) без перезагрузки страницы.

## 2. Управление Логикой Расчета (Calculator Engine Terminal)

**Новый модуль!** Полный контроль над математическим ядром системы без участия
программистов.

> **Adaptive UI**: Интерфейс конфигуратора полностью адаптирован под **Svetluy
> (Light)** и **Dark** темы для комфортной работы в любое время суток.

- **Редактор Формул (Formula Editor)**:
  - **Visual Builder**: Режим для менеджеров. Выбор метода (MAX/SUM) и
    включение/отключение множителей кликами.
  - **Code Editor (Advanced Mode)**: Режим для архитекторов. Прямое написание
    математических выражений (String Equation) для ядра расчета.
    - Поддержка переменных: `q_area`, `q_staff`, `q_visitors`.
    - Поддержка функций: `max()`, `sum()`, `avg()`, `sqrt()`, `ceil()`.
    - Поддержка коэффициентов: `k_zone`, `k_intensity`, `k_reserve`.
- **Зоны и Помещения**:
  - Управление списком доступных зон (Лобби, Кухня, Туалет и т.д.).
  - Настройка базовых коэффициентов сложности для каждой зоны.
- **Типы Объектов**:
  - Настройка типов зданий (Отель, Ресторан, ТЦ).
- **Коэффициенты**:
  - Тонкая настройка процентов запаса (Reserve) для разных уровней риска.
  - Калибровка множителей интенсивности (Low/Medium/High Load).
- **Персистенция**: Изменения применяются мгновенно ко всем новым расчетам.

## 3. Брендирование (White Labeling)

Система полной визуальной кастомизации платформы под клиента (SaaS).

- **Название приложения**: Установка кастомного имени системы (вместо HICS).
- **Темы**: Поддержка Светлой и Тёмной темы + Системная.
- **Цветовая палитра**: Настройка Brand Color, фона, текста.
- **Интерфейс**: Настройка радиусов скругления.
- **Live Preview**: Предпросмотр изменений в реальном времени.

## 4. Управление Командой (Team)

Полное управление пользователями и доступом.

- **Список пользователей**: Просмотр, поиск, фильтрация.
- **Роли**: Назначение (Клиент/Менеджер/Админ).
- **Приглашения**: Email-инвайты с пре-ролями.

## 5. Реестр Товаров и Поставщиков

Управление базой данных оборудования.

- **Товары**: CRUD операции, поиск, цены, нормативы.
- **Поставщики**: Логотипы (с защитой от сбоев), контакты, типы интеграции.

## 6. Управление Проектами (Projects)

Глобальный реестр всех расчетов.

- **Мониторинг**: Статусы, бюджеты, ответственные менеджеры.
- **Действия**: Назначение менеджера, возврат статуса, удаление.

## 7. Аудит (Audit Logs)

Журнал событий безопасности.

- **Логирование**: Вход, создание, удаление, изменение настроек.
- **Детали**: IP, UserAgent, Timestamp.

---

**Технические особенности:**

- **Отказоустойчивость**: Система "тихого" обновления данных.
- **Hot-Swap Engine**: Логика калькулятора (CalculationEngine) поддерживает
  "горячую" замену формул на лету через конфиг.
