# Будущее развитие: Supabase Edge Functions 🚀

Этот документ описывает стратегические направления использования Edge Functions
для превращения **Calculator Service** из простого инструмента в мощную
экосистему автоматизации.

---

## 1. Документооборот и PDF (High Priority)

Перенос генерации документов на сервер гарантирует их единообразие и
безопасность.

- **Генерация Инвойсов:** Автоматическое создание PDF-счета при переходе в
  статус `Ожидает оплаты`.
- **Экспертное заключение:** Формирование подробного PDF-отчета (Аудит проекта)
  с логотипом компании, детализацией по зонам и HACCP-рекомендациями.
- **Подготовка спецификаций:** Экспорт итогового списка товаров в Excel (XLSX)
  для отдела закупок.

## 2. Искусственный интеллект и Аудит (Innovation)

Использование LLM (GPT-4) для автоматизации первичной проверки.

- **Предварительный аудит:** При подаче заявки клиентом, AI проверяет состав
  инвентаря на соответствие стандартам (например: "В зоне разделки мяса
  отсутствует цветовое кодирование ножей").
- **Умный Чат-бот:** Автоматические ответы на часто задаваемые вопросы клиентов
  по расчетам прямо в чате, пока менеджер занят.
- **Классификация запросов:** Определение сложности проекта и автоматическое
  назначение на более опытного менеджера.

## 3. Финансовый контроль и Безопасность (Operations)

Автоматизация рутинных проверок оплаты.

- **OCR Проверка Чеков:** При загрузке фото чека функция использует
  распознавание текста для сверки суммы, даты и номера заказа.
- **Верификация транзакций:** Интеграция с банковскими Webhooks для мгновенного
  подтверждения оплаты без участия менеджера.

## 4. Retention и Уведомления (Engagement)

Поддержание активности пользователей и менеджеров.

- **Робот-напоминалка:** Ежедневная проверка "зависших" проектов. Если клиент не
  платит более 3-х дней, робот пишет вежливое напоминание в чат.
- **Telegram/Slack Мост:** Пересылка важных событий (новая заявка, оплата) в
  рабочие чаты команды.
- **Cleanup Lock System:** Автоматическое снятие "брони" (пессимистической
  блокировки) с проекта, если менеджер не проявлял активность более 1 часа.

## 5. Интеграции и Синхронизация (Ecosystem)

Связь с внешним миром.

- **CRM Sync:** Автоматическая отправка данных о клиенте и сумме сделки в CRM
  (AmoCRM, Bitrix24) при каждой продаже.
- **Складской учет:** Синхронизация остатков товаров с основной базой или
  системой поставщиков.
- **Сбор аналитики:** Отправка анонимизированных данных о спросе в BI-системы
  (например, Google Looker Studio).

---

## Архитектурное преимущество

Использование Edge Functions позволяет нам:

1. **Снизить нагрузку на фронтенд:** Браузер занимается только UI.
2. **Повысить безопасность:** Секретные ключи API хранятся в защищенной среде.
3. **Обеспечить масштабируемость:** Каждая функция работает изолированно и
   потребляет ресурсы только в момент вызова.
