# HICS — Professional Inventory Management Ecosystem

![Version](https://img.shields.io/badge/version-2.1.0--PRO-blue?style=for-the-badge)
![Tech](https://img.shields.io/badge/Stack-React%20%7C%20Supabase%20%7C%20TypeScript-orange?style=for-the-badge)

**HICS (HoReCa Inventory Calculation System)** — это высокотехнологичная экосистема для профессионального расчета и управления закупками инвентаря в секторе HoReCa. Приложение объединяет в себе мощный математический движок, систему коммуникации в реальном времени и экспертную экспертизу.

---

## 🚀 Основные возможности

### 1. Интеллектуальный расчет (Engine v2.0)
Автоматизированный расчет норм расхода на основе уникальных формул, учитывающих:
- Тип и площадь зон (HACCP-стандарты).
- Соотношение персонала и проходимости.
- Коэффициенты интенсивности и циклы замены.
- Стандарты цветового кодирования (пищевая безопасность).

### 2. Реалтайм-синхронизация (Senior Sync)
Двухсторонняя связь между клиентом и менеджером:
- Мгновенные уведомления о правках (`Broadcasting`).
- Автоматическое обновление данных без перезагрузки страницы.
- Механизм защиты от конфликтов при редактировании.

### 3. Ролевая модель доступа
- **Client**: Создание расчетов, настройка зон объекта, чат с экспертом.
- **Manager**: Аудит входящих заявок, калибровка смет, сопровождение клиентов.
- **Admin**: Глобальное управление мастером инвентаря и пользователями.

## 🛠 Технологический стек

- **Core**: React + Vite (сверхбыстрая сборка).
- **Language**: TypeScript (строгая типизация для исключения Runtime ошибок).
- **Backend / Realtime**: [Supabase](https://supabase.com/) (PostgreSQL, Auth, Broadcast).
- **Styling**: Tailwind CSS 4.0 + Custom Glassmorphism System.
- **UI Components**: Lucide Icons, Sonner (премиальные уведомления), Framer Motion (анимации).

---

## 🛡 Production-Ready архитектура

- **Global Error Boundary**: Система защиты от падений интерфейса.
- **Service Layer**: Четкое разделение бизнес-логики (`chatService`, `calculationsService`) от UI.
- **SEO & Social Branding**: Настроенные OpenGraph теги и динамические заголовки для продвижения.
- **Security**: Защищенные маршруты (`ProtectedRoute`) и строгая политика RLS на уровне базы данных.
